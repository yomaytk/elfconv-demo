elfconv Demo

This is the demo page for elfconv which runs WebAssembly converted from Linux applications.

Shell Environment (GNU Bash + BusyBox)

Overview

This is a demonstration of running WebAssembly versions of statically linked Linux/aarch64 applications—GNU Bash and BusyBox. You can use Bash as an interactive shell and execute various BusyBox utilities via symlinks under /usr/bin.

⚠️ Caution: Many BusyBox commands are untested. As a result, they may occasionally terminate with runtime errors. If this happens, please reload the page.

Python Environment

Overview

This is a demonstration of CPython ported to WebAssembly and running directly in your browser. You can run Python scripts and use the interactive interpreter. Try running python --version or python -c "import sys; print(sys.version)" to see the Python environment in action!
